# 👑 Creator King

All the essential utility tools for content creators in one powerful, privacy-first web application. 100% Client-Side and fully automated.

## 🚀 Key Features
* **Zero Server Uploads**: All media, video, text, and metadata operations run 100% locally in your browser using secure client-side sandboxing. Maximum speed and zero data leaks.
* **Folder-Based Architecture**: Dynamic tool discovery built on top of Vite. Adding a tool is as simple as dropping a file.
* **40+ Global Languages**: Complete built-in i18n localization support for creators worldwide.
* **Built for Scale**: Fully responsive PWA designed to work smoothly across all devices, including tablets and mobile phones.

## 🛠️ Project Structure
* `src/tools/` - The modular core where individual tools reside.
* `src/locales/` - Automated JSON translation sets for global reach.
* `src/components/` - Reusable Vanilla UI components.
